A Little Bit More About This Site

I was inspired to make this site after viewing videos online that showed different animated charts of artists or specific years over time. I wanted something similar for myself, so I, originally, manually collected the data and graphed the data myself. During a talk with a friend, who is a software engineer, he suggested that I should automate the website, which I held off doing until winter break of senior year. At first, the automation was only for myself and I still had to manually create playlists with my top songs on Spotify (On Repeat Playlist). During my freshman year, I added more functionalities to my program. In my sophomore year of college, I decided to switch to using the Last.fm API to be able to get more accurate data without having to do anything manually on my end. With this switch, I was also able to allow other people use my program, so I thought of creating a website. I have little formal experience with website design, but I used what I can and learned more about specific components that I wanted to be in my website. During my summer before Junior Year, I was able to finally publish the first version of my website. I hope you enjoy!

Check out the Github and see the code for yourself!

Roadmap for the Future (in no particular order):

  • Albums Chart: Use album data instead of songs.
  • Artists Chart: Use artist data instead of songs.
  • Variant Grouping: Create a smart system to combine different album and song versions to be associated with the Standard Version
  • Group Chart: Use multiple user's data to create a chart (and adjust point system for this)
  • Improve UI/UX of website: Add transitions, clean up elements, etc.
  • Optimization: Improve speed of the site wherever possible.
