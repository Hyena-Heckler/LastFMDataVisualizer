# LastFMDataVisualizer
Using data from LastFM to help develop visualizations of the data in the form of animated charts and other graphics.

Web Demo [Formatted for Desktops]: https://last-fm-data-visualizer.vercel.app/

This application connects to the Last.fm API to gather listening data for the user. It stores the data on Neon PostgreSQL to avoid repeated calls to Last.fm. The website uses a NodeJS backend (for basic transformation of data and to connect to databases) and Python backend (for heavy data calculations) to calculate top songs for the user and various other statistics for the user.
